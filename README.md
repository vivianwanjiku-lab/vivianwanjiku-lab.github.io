# Vivian Wanjiku | Portfolio

A one-page static site made of `index.html` and `style.css`. There's no build step and nothing to install.

1. **Preview it:** double-click `index.html` to open it in your browser.
2. **Edit the content:** open `index.html` in any text editor and search for `EDIT` and `REPLACE`. Comments mark each bit of text you may want to change. The email `hello@example.com` is a **placeholder**, so swap in your real address before publishing.
3. **Update projects:** each project is an `<article class="card">` block in the Work section. Change its title, description, tags, and the Code / Live demo links. Thumbnail colours are the `.thumb--1` to `.thumb--6` gradients in `style.css`.
4. **Publish free on Netlify:** go to https://app.netlify.com/drop and drag this folder onto the page. You'll get a live link in seconds.
5. **Or publish on GitHub Pages:** create a public repo (for example `<username>.github.io`), upload these files, then open *Settings → Pages*, choose the `main` branch and `/ (root)`, and save.
6. **Update later:** edit the files, then re-upload them (Netlify) or commit the changes (GitHub Pages).

# Vivian Wanjiku | Portfolio

A one-page static site made of `index.html` and `style.css`. There's no build step and nothing to install.

1. **Preview it:** double-click `index.html` to open it in your browser.
2. **Edit the content:** open `index.html` in any text editor and search for `EDIT` and `REPLACE`. Comments mark each bit of text you may want to change. The Contact section holds the email (`vividorpass@gmail.com`), the phone number (`0740 758 072`, linked as `tel:+254740758072`) and the GitHub link.
3. **Contact form:** visitors' messages and suggestions are emailed to you through [FormSubmit](https://formsubmit.co), with no server needed. The destination is the `data-endpoint` URL on the `<form id="contact-form">` in `index.html`. The first submission triggers a one-time activation email from FormSubmit, and you must click its link before messages start arriving.
4. **Update projects:** each project is an `<article class="card">` block in the Work section. Change its title, description, tags, and the Code / Live demo links. Thumbnail colours are the `.thumb--1` to `.thumb--6` gradients in `style.css`.
5. **Publish free on Netlify:** go to https://app.netlify.com/drop and drag this folder onto the page. You'll get a live link in seconds.
6. **Or publish on GitHub Pages:** create a public repo (for example `<username>.github.io`), upload these files, then open *Settings → Pages*, choose the `main` branch and `/ (root)`, and save.
7. **Update later:** edit the files, then re-upload them (Netlify) or commit the changes (GitHub Pages).

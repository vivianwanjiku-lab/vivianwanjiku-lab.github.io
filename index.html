About

About me

I'm a full-stack developer who enjoys taking an idea all the way to a working app. On the front end I use React and JavaScript to build responsive interfaces. On the back end I write REST APIs in Python with Flask and SQLAlchemy, backed by SQL databases.

My recent work includes team projects such as Recipe Swap Hub and TapNet, plus smaller APIs and command-line tools with automated tests in pytest. Right now I'm going deeper on REST API design, testing, Docker and CI/CD.
